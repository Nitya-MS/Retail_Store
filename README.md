# Retail_Store

**Business scenario**
A retail company receives customer, product, store, and sales data from different sources. The company wants a centralized analytics platform for reporting and business analysis.

**Main objectives**
The platform should:

Ingest new files incrementally.

Store raw data in a Bronze layer.

Clean and validate data in Silver.

Maintain customer history using SCD Type 2.

Create business-ready Gold tables.

Capture rejected records instead of deleting them.

Run automatically every day.

Provide data for dashboards and analytics.
